به استانداردهای بین‌المللی استناد نشده است. مثال‌هایی که از کتاب نیستند برچسب «مثال فرضی» دارند.

## بازسازی فایل‌ها

```bash
cd presentation
pip install python-pptx python-docx pillow
python3 build.py                                            # همه فایل‌های تحویلی
python3 build.py --from 16 --to 21 --out scratch/part.pptx  # بازه دلخواه
```

- `deck/theme.py` رنگ‌ها و اندازه‌ها، `deck/kit.py` ابزارهای راست‌به‌چپ.
- `deck/slides_a.py` تا `slides_d.py` خود اسلایدها.
- `deck/script.py` متن ارائه هر اسلاید؛ `deck/script_doc.py` سازنده فایل Word.
- `tools/render_preview.py` سازنده تصویر پیش‌نمایش (نیازمند `Spire.Presentation`).

## پیش‌نمایش

- `index.html` صفحه پیش‌نمایش همه اسلایدها با متن ارائه و دکمه‌های دانلود.
- `preview/slide-01.jpg` تا `slide-27.jpg` تصویر هر اسلاید. خط کم‌رنگ انگلیسی بالای تصاویر مربوط به ابزار پیش‌نمایش است و در فایل پاورپوینت نیست.
