نصب و اجرا — دقیقاً از همین برنچ

ویندوز ۱۰/۱۱ + پایتون ۳.۱۰ به بالا. برای چت واقعی: Node 18+ و npm install -g @anthropic-ai/claude-code و یک بار claude → /login.

# 1) کلونِ همان برنچی که PR از آن باز شده git clone -b arena/02f5758d-app-claude-code-fcc https://github.com/maghroonv-netizen/app_claude_code_FCC.git cd app_claude_code_FCC
# 2) محیط مجازی + وابستگی‌ها (ویندوز) python -m venv .venv .venv\Scripts\pip install -r requirements-dev.txt
# 3) اجرا .venv\Scripts\python run.py # حالت واقعی .venv\Scripts\python run.py --demo # دموی آفلاین بدون CLI
# 4) تست‌ها .venv\Scripts\python -m pytest set FCC_E2E=1 && .venv\Scripts\python -m pytest # + end-to-end با CLI واقعی

ساخت exe و نصب‌کننده (فقط روی ویندوز)

خروجی: پوشهٔ اپ + zip پرتابل + ClaudeCodeStudio-Setup-1.0.0-x64.exe. یا تگ بزنید تا CI خودش Release بسازد.

.venv\Scripts\python tools\build_windows.py --output build\output --installer # گزینه‌ها: --onefile --console --clean # یا Release خودکار: git tag v1.0.1 && git push --tags

اگر به مشکل خوردید

همهٔ اینها روی همین برنچ کار می‌کنند؛ خروجی‌ها را نگه دارید تا دیباگ سریع باشد.

CLI پیدا نشد / نسخه ناشناخته

مسیر را در Settings → CLI path بدهید یا python run.py --cli "C:\path\claude.cmd". گزارش کامل: python run.py --diagnostics

خطای احراز هویت (Not logged in)

یک بار در ترمینال claude را اجرا و /login کنید. اپ، hint دقیق را در Diagnostics نشان می‌دهد.

لاگ‌ها و crash-report کجاست؟

%APPDATA%\ClaudeCodeStudio\logs — برای لاگ زندهٔ کنسول: python run.py --console-log

برگشتن به تنظیمات اولیه

python run.py --reset-config یا متغیر FCC_DATA_DIR برای مسیر دادهٔ دلخواه.

تست Qt روی لینوکس headscreen خطای libGL می‌دهد

python tools/make_stublibs.py سپس LD_LIBRARY_PATH=~/.cache/fcc-stublibs python -m pytest
